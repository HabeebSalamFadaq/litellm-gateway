## What you need to do in the Railway dashboard (5 minutes)

1. Open https://railway.com/dashboard
2. Click project `motivated-creativity` (or the new one if you start fresh)
3. Click the **litellm** service
4. **Settings** tab:
   - **Healthcheck Path**: clear it (empty) OR set to `/health/liveliness` with timeout 300s
   - **Target Port**: 4000
   - **Custom Start Command**: `litellm --config /app/config.yaml --port 4000 --host 0.0.0.0` (after you mount the config)
5. **Variables** tab → confirm these are set:
   ```
   LITELLM_MASTER_KEY=sk-litellm-gateway-BdWGjmNnHfS2qs9eTbgAQJPrcIL6xXOp
   LITELLM_SALT_KEY=any-random-32-char-string-never-change-after-set
   PORT=4000
   DISABLE_SCHEMA_UPDATE=true
   GEMINI_API_KEY_1=AIza...   (all 6 Gemini keys)
   OPENROUTER_API_KEY_1..4=sk-or-v1-...
   OPENCODE_ZEN_API_KEY=sk-JtAK...
   NVIDIA_NIM_API_KEY=nvapi-...
   ```
